# What's My Kernel Writeup

## Summary

The challenge leaks images of the same torsion basis that defines Alice's secret kernel. Since `phi(P_a) + n phi(Q_a) = 0`, the hidden flag integer is just a discrete logarithm in a smooth `2^216`-order group.

Flag:

```text
crypto{whoops_this_was_just_a_dlog}
```

## Triage

`output_f0f36907a0a0be13b6587ab3cfdde72a.txt` shows `P_b = P_a` and `Q_b = Q_a`, which is the implementation bug. `solve.sage` reconstructs the public curve and leaked images.

## Solve Path

The kernel is generated by:

```text
R = P_a + n Q_a
```

Because `R` maps to zero under `phi`, the public images satisfy:

```text
phi(P_a) = -n phi(Q_a)
```

The solve uses Sage's generic discrete log over the `2^216` torsion subgroup and converts `n` back to bytes.

```bash
sage solve.sage
```

## Lessons Learned

- Leaking images of the basis that defines a hidden kernel can collapse SIDH-style secrecy to DLOG.
- Smooth prime-power torsion makes the discrete logarithm practical.
