# Two Isogenies Writeup

## Summary

This SIDH-road challenge asks for the codomain of a 2-isogeny from `E: y^2 = x^3 + x` over `GF(p^2)`. The kernel is generated by the order-2 point `(i, 0)`, so Sage can compute the isogeny directly.

Flag:

```text
j(E') = 287496
```

## Triage

`solve.sage` defines `p = 2^18 * 3^13 - 1`, the quadratic extension with `i^2 = -1`, and the kernel point `K = (i, 0)`.

## Solve Path

The point is verified to have order 2:

```python
K = E(i, 0)
assert 2 * K == E(0)
```

Then Sage's isogeny constructor gives the codomain:

```python
phi = E.isogeny(K)
E2 = phi.codomain()
print("j(E') =", E2.j_invariant())
```

## Exploit

Run:

```bash
sage solve.sage
```

## Verification

```text
$ sage solve.sage
j(E') = 287496
```

## Flag

```text
j(E') = 287496
```

## Lessons Learned

- A cyclic kernel generator is enough for Sage to construct the corresponding isogeny.
- For degree 2, Velu's formulas can also be checked by hand as a sanity test.
