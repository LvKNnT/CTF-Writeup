# Three Isogenies Writeup

## Summary

The task is the same basic isogeny construction as the previous starter, but with a degree-3 kernel. The solution verifies the kernel order, computes the isogeny, and returns the codomain j-invariant.

Flag:

```text
j(E') = 96392670793
```

## Triage

`solve.sage` defines the base curve over `GF(p^2)` and a point `K` with order 3.

## Solve Path

Sage constructs the subgroup generated by `K` internally:

```python
assert 3 * K == E(0)
phi = E.isogeny(K)
E3 = phi.codomain()
```

The j-invariant of `E3` is the requested answer.

## Exploit

Run:

```bash
sage solve.sage
```

## Verification

```text
$ sage solve.sage
j(E') = 96392670793
```

## Flag

```text
j(E') = 96392670793
```

## Lessons Learned

- Degree-3 isogenies are still direct once the kernel generator is known.
- Printing an isomorphism-invariant such as `j` avoids dependence on the exact codomain model.
