# whats a lattice Writeup

## Summary

This introductory lattice challenge asks for the volume of a lattice generated by the provided basis. The solve script computes the determinant of the basis matrix and takes its absolute value as the lattice volume.

Answer:

```text
255
```

## Triage

The folder contains `solve.sage`, which defines the basis vectors and builds a Sage matrix. For a full-rank square lattice basis, the fundamental volume is:

```text
abs(det(B))
```

## Solve Path

The determinant of the basis matrix is `-255`, so the lattice volume is `255`.

## Exploit

Run the standalone Sage script:

```bash
sage solve.sage
```

It constructs the matrix, computes its determinant, and prints the absolute determinant.

## Lessons Learned

- The determinant of a square basis matrix gives the signed volume of its fundamental parallelepiped.
- Lattice volume is the absolute value of that determinant.
- Sage matrices are convenient for exact integer lattice arithmetic.
