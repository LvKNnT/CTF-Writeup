# Find the Lattice Writeup

## Summary

This challenge is an NTRU-style lattice recovery problem. The public parameters `q`, `h`, and ciphertext `m` define a two-dimensional lattice containing a short private basis `(f, g)`. LLL recovers that short basis, allowing the ciphertext to be decrypted.

Flag:

```text
crypto{Gauss_lattice_attack!}
```

## Triage

The provided source and output expose the NTRU-like relation:

```text
h = f^-1 * g mod q
```

That means `(f, g)` is a short vector in the lattice generated by:

```text
[1 h]
[0 q]
```

## Solve Path

The solver builds the lattice basis and applies LLL:

```python
M = Matrix([[1, h], [0, q]])
L = M.LLL()
f, g = L[1]
```

With `f` and `g`, decryption follows the NTRU-style formula:

```text
a = f * e mod q
m = a * f^-1 mod g
```

The resulting integer decodes to the flag bytes.

## Exploit

Use `solve.sage`. It:

- builds the two-dimensional public lattice,
- recovers the short vector with LLL,
- decrypts the ciphertext,
- converts the integer to bytes.

Run:

```bash
sage solve.sage
```

## Lessons Learned

- NTRU-like public keys can reveal a short private vector in a public lattice.
- LLL is enough for very low-dimensional short-vector recovery.
- Once the short basis is recovered, decryption is straightforward modular arithmetic.
